## 0. 이 계획이 제안하는 가장 큰 변경

**말씀하신 V1/V2/V3 순서를 뒤집는 것을 제안합니다.**

제안하신 순서는 이랬습니다:
- V1: 온보딩 → 추천 3개 → 레퍼런스 → 선택 → 프로젝트 → 체크리스트 → 게시
- V2: 편집본 업로드 → AI 영상 분석
- V3: YouTube Analytics 연동

**제안: V1에 영상 분석을 넣고, 기획 루프를 V2로 미룹니다.**

근거 3가지:

1. **V1 목록에 있는 모든 기능이 이미 무료입니다.** 추천 3개+이유는 YouTube Studio Inspiration 탭이, 채널 데이터 기반 코칭은 Ask Studio가 **한국어로** 무료 제공합니다. 이걸로 "돈 낼 의향"을 검증하면, 검증되는 건 아무것도 없습니다. 사용자는 "좋네요"라고 하고 결제창에서 나갑니다.

2. **레퍼런스 영상 분석은 법적으로 만들 수 없습니다.** V1의 차별화 요소로 넣으셨는데, YouTube 정책상 남의 영상을 다운로드·디코딩할 수 없고 채널 간 집계도 금지입니다(리서치 1장). 이걸 빼면 V1에는 차별점이 하나도 남지 않습니다.

3. **돈을 낼 만한 유일한 기능이 영상 분석입니다.** 그리고 목표가 "가장 짧은 개발 기간으로 돈 낼 가능성 검증"이라면, 검증 대상을 먼저 만들어야 합니다.

**그리고 지금까지 만든 것은 하나도 안 버립니다.** 온보딩 5문항(`channels`의 카테고리·영상형태·목표·소개·업로드빈도)이 **장르별 분석 기준을 고르는 입력**이 됩니다. 인증·DB·RLS·배포도 그대로입니다.

# 요청하신 17개 항목

## 1. 새 제품 한 문장 정의

> **한국 유튜버가 편집을 끝낸 영상을 올리면, 어디를 어떻게 고쳐야 하는지 시간대별로 알려주는 AI 편집 코치.**

부제(2단계): "그리고 다음에 뭘 찍을지까지 같이 관리합니다."

⚠️ **"AI 채널 매니저"는 최종 지향점으로는 좋지만 V1의 판매 문구로는 너무 넓습니다.** 넓은 약속은 초보 사용자가 "그래서 뭘 해주는데?"를 이해하지 못하게 만듭니다. V1은 하나만 말하십시오.

## 2. 핵심 고객

- 한국 유튜버, 구독자 0~10,000명
- **혼자 촬영·편집·업로드하는 1인 크리에이터**
- 영상은 만들고 있지만 "이게 재미있는지 스스로 판단이 안 되는" 사람
- ⚠️ **좁히기 제안**: "아직 아무것도 안 올려본 사람"이 아니라 **"이미 몇 개 올렸는데 잘 안 되는 사람"**을 초기 타깃으로 하십시오. 후자만이 편집본을 갖고 있고, 문제를 자각하고 있으며, 돈을 낼 이유가 있습니다.

## 3. 가장 강한 문제

말씀하신 7개 중 **6번이 압도적으로 강합니다.**

> **"편집을 끝내도 영상이 지루한지 스스로 판단하기 어렵다."**

이유:
- 1인 크리에이터는 **피드백을 줄 사람이 없습니다.** 편집자도, PD도, 동료도 없습니다.
- 자기 영상은 수십 번 봐서 객관적 판단이 불가능합니다.
- 게시 후에야 리텐션 그래프로 알게 되는데, **그때는 이미 늦었습니다.**
- 그리고 **아무도 이 문제를 한국어로 풀어주지 않습니다.**

1~4번(뭘 찍을지, 뭘 고를지, 뭘 참고할지)은 YouTube가 무료로 풀어주고 있고, 5번(못 끝냄)과 7번(다음에 뭘 개선할지)은 진짜지만 6번보다 지불 의사가 약합니다.

## 4. 경쟁 대비 실제 차별점

정직하게 3단계로 나눕니다.

| 차별점 | 실제 강도 |
|---|---|
| 🔴 "편집본 업로드 → 타임스탬프 피드백" | **차별점 아님.** 영어권에 PreViral, Retti, Retention Rabbit, Satura 4개가 이미 함. Retti는 "Editing Lab"이라는 이름으로 거의 동일 |
| 🟡 "한국어로 한다" | **진짜지만 얕음.** 번역 레이어는 누구나 붙일 수 있음 |
| 🎯 **"한국식 자막(예능 자막) 분석"** | **진짜 해자.** 학술적으로 문서화된 구조적 차이(한국 예능 프로그램당 제3자 자막 약 1,000개 vs 미국 0개). **서구 경쟁사는 이 축의 존재조차 모름.** 기술적으로도 의미론적 판단보다 쉬움 |
| 🎯 **장르별 기준 + 근거 등급 표시** | **진짜.** 경쟁사는 전부 단일 기준. 그리고 "이건 YouTube 공식 / 이건 연구 데이터 / 이건 업계 관행"을 구분해 보여주는 곳이 없음 → **정직함 자체가 차별점** |
| 🎯 **쇼츠 UI 오버레이 영역 레이아웃 체크** | 조사 범위에서 **아무도 안 함.** 값싸고 검증 가능 |
| ✅ 기획→제작→업로드 운영 루프 | 진짜지만 **V2 이후.** 앞에서 결론 낸 대로 |

**⚠️ 경쟁사 4곳이 전부 소규모입니다** — 투자·리뷰·커뮤니티 언급 거의 없고 가격이 $9~59에 몰려 있습니다(= 아무도 가격 결정력을 못 찾음). 위협이자 경고입니다.

## 5. MVP V1 — "AI 편집 코치" (권장 4~6주)

**한 문장: 편집본을 올리면 한국어로 시간대별 수정 제안을 받는다.**

| 포함 | 내용 |
|---|---|
| 기존 온보딩 재사용 | `channels`의 카테고리/영상형태 → **장르 자동 선택** |
| MP4 업로드 | 브라우저에서 480p 축소(WebCodecs) → Supabase 직접 업로드 |
| FFmpeg 단일 패스 (Cloud Run) | 샷 목록, 무음, 음량, 정지화면, 검은화면, 키프레임 |
| 전사 | Groq whisper-large-v3-turbo → 단어 타임스탬프 |
| 규칙 엔진 (CPU, $0) | 샷 길이 이상치 / 공백 / 정지 / 음량 / 발화 속도 |
| 🎯 **자막 분석** | 자막 밀도(분당), 자막 공백 구간, 가독성 — **차별점** |
| 최종 LLM | 타임스탬프 기반 한국어 피드백 |
| 결과 화면 | 타임라인 + 구간별 카드 + **근거 등급 표시** |
| 장르 | **4개만** (브이로그 / 정보형 / 리뷰·언박싱 / 스토리·썰) |
| 결제 | 7일 체험(카드 필수) → 월 구독 |

**V1에서 빼는 것:**

| 뺄 것 | 이유 |
|---|---|
| 🔴 레퍼런스 영상 분석 | **법적으로 불가** (리서치 1장) |
| 추천 3개 / 제목 / 썸네일 / 훅 / 영상구조 생성 | 전부 무료로 존재. 지불 의사 없음 |
| 프로젝트 / 체크리스트 | V2 |
| YouTube Analytics 연동 | V3 |
| 리텐션 예측 | **영원히 안 함** (10번 참고) |
| 쇼츠 모드 | V3. 별개 제품 화면이라 V1에 넣으면 두 배 일 |
| ASMR·음악 등 나머지 장르 | 틀린 조언이 미지원보다 나쁨 |
| 다중 채널 | 스키마는 이미 지원. 나중에 버튼만 |

## 6. V2 — 운영 루프 (V1 검증 후)

원래 사장님 구상의 앞부분입니다. **V1으로 돈 내는 사람이 확인된 다음에** 붙입니다.

- 추천 3개 (순위 + 이유) — 단, **판매 문구가 아니라 부가 기능으로**
- "이 영상으로 결정" → `content_projects` 생성 (스키마 이미 준비됨)
- 촬영·편집 체크리스트 (**고정 템플릿 + 사용자 편집** 권장, AI 생성 아님)
- 상태 전환 → 업로드 완료
- **성과 수동 입력** (조회수 1칸)
- 🎯 **핵심 연결: 분석했던 영상 = 프로젝트 = 성과.** 여기서 처음으로 "내 지난 영상 대비" 피드백이 가능해집니다
- 사람이 쓴 **장르 플레이북** (레퍼런스 분석의 합법적 대체재)

## 7. V3 — 개인화 + 확장

- **YouTube Analytics 연동** — 본인 채널이므로 **Authorized Data**라 장기 보관 허용(30일마다 권한 재확인 조건)
- "당신의 지난 최고 성과 영상과 비교하면" — **레퍼런스 분석보다 안전하고 제품적으로도 우월**
- 노출수·CTR (Reporting API, **48시간 지연** 주의)
- 쇼츠 전용 모드 (레이아웃 체크 포함)
- 장르 확대 (먹방, 뷰티, 재테크, 교육)
- 주간 채널 전략 리포트

## 8. 편집본 분석 기술 아키텍처

```
브라우저 (WebCodecs — 점유율 93.6%)
  └ 480p 축소 재인코딩 → 8~10배 작아짐
  └ 16kHz 모노 Opus 오디오 별도 추출
       ↓ Supabase 직접 업로드 (signed URL, resumable)
       ↓ ⚠️ Vercel 절대 경유 금지 — 요청 본문 4.5MB 상한
Supabase Storage (Pro 필수 — Free는 업로드 50MB 상한이라 사용 불가)
       ↓
Google Cloud Run (⚠️ Vercel 불가 — 30분 영상 304초 > Hobby 300초 상한)
  └ FFmpeg 단일 패스 (따로 4번보다 45% 빠름):
       scdet=t=10            ← ⚠️ 제안하신 gt(scene,0.4)는 79%만 검출
       -skip_frame nokey     ← fps=1보다 7.5배 빠름
       ebur128 + silencedetect + blackdetect + freezedetect
  └ Groq whisper-large-v3-turbo ($0.04/시간)
       ↓
  규칙 엔진 (순수 CPU, $0) ← 피드백의 11/15가 여기서 나옴
    → 이상치 탐지 + "비전을 볼 가치가 있는 20~40 프레임" 선정
       ↓
  Vision (선별 프레임만, 자막 분석은 512×288 이상 필요)
       ↓
  최종 LLM → 타임스탬프 한국어 피드백
```

**제안하신 파이프라인에서 바꿀 3가지** (상세는 `research-video-analysis.md` 9장):
1. "중복 프레임 제거" 별도 단계 삭제 — 값싼 신호가 프레임을 고르게
2. "1fps 샘플링" → `-skip_frame nokey`
3. 4단계를 FFmpeg 1회 호출로 통합

## 10. 수익화 구조

**제안하신 7일 체험 → 월 구독이 맞습니다.** 다만 3가지 조정:

**① 영상 분석은 "무제한"이 아니라 월 분(minutes) 한도로.**

| 플랜 | 가격 | 월 분석 한도 |
|---|---|---|
| **체험** | 7일 무료, **카드 필수** | **1개, 10분까지** |
| **Creator** | 14,900원 전후 | 월 **120분** (30분 영상 4개 / 10분 영상 12개) |
| **Pro** | 29,900원 전후 | 월 **400분** + 장르 전체 + (V3) Analytics 연동 |

"영상 개수"가 아니라 **분(minutes)**으로 재는 게 맞습니다 — 비용이 길이에 비례하기 때문입니다.

**② 체험에서 얼마나 보여줄 것인가**

**전체 분석을 1개, 10분까지 완전히 보여주십시오.** 일부만 가리는 방식(예: 첫 3개 피드백만)은 비추천입니다 — 이 제품의 가치는 "구간 전체를 훑어준다"는 데 있어서, 가리면 가치가 전달되지 않습니다. **10분 제한 + 카드 필수 + 1회**로 어뷰징을 막고 가치는 온전히 보여주는 게 낫습니다.

**③ 어뷰징 방지 우선순위** (Stripe 문서 기준)
1. **체험 시작에 카드 등록** ← 가장 강력한 단일 통제
2. **서버에서 하드 캡** — 계정별/일별/**총 업로드 분**
3. 일회용 이메일 차단
4. 기기 지문 + IP 가입 속도
5. **2~4주는 관찰만** 하고 차단은 나중에 (진짜 초보를 막지 않기 위해)

⚠️ 기기 지문·IP는 개인정보 처리 → 개인정보처리방침 고지 필수. **휴대폰 본인확인은 본인확인기관 계약이 필요하니 직접 만들지 마십시오.**

⚠️ 🔴 **Stripe는 한국 사업자를 받지 않습니다.** 국내 PG(토스페이먼츠/포트원 등) 또는 Paddle 같은 MoR을 써야 합니다.

## 11. 반드시 제거해야 할 기능

| 제거 | 이유 |
|---|---|
| 🔴 **레퍼런스 영상 자동 분석 (다운로드·프레임 분석)** | **YouTube 정책 명시적 금지.** "download, import, backup, **cache**, or store copies of YouTube audiovisual content" |

## 15. 실제 사용자 10명 테스트 방법

**전제: 처음부터 유료로.** "무료로 써보시고 좋으면 나중에 결제"는 검증이 아닙니다.

1. **모집처**: 한국 유튜버 커뮤니티(디시 유튜버갤, 클리앙, 아프리카/치지직 소통방), 유튜브 관련 오픈채팅, 구독자 1,000~5,000명 채널에 직접 DM. **10명이면 손으로 충분합니다.**
2. **자격 조건**: 최근 3개월 내 영상 3개 이상 올린 사람 (편집본이 있고 문제를 자각하고 있음)
3. **제안**: "7일 무료, 이후 월 14,900원. 대신 30분만 통화해주세요."
4. **측정할 것**: 결제 전환 / 업로드 완료율 / **재업로드율** / 7일·30일 재방문
5. **물어볼 것**:
   - "이 피드백 중 실제로 고칠 것은 몇 개인가요?" ← 품질의 진짜 척도
   - "이걸 안 쓰면 지금 어떻게 하시나요?" ← 대체재 확인
   - "얼마면 계속 쓰시겠어요?" ← 가격 감각
   - "친구에게 추천하시겠어요? 뭐라고 설명하실 건가요?" ← 포지셔닝 검증
6. **본인 영상으로 먼저** 20개 돌려보고 품질을 확인한 뒤 사람을 부르십시오.
