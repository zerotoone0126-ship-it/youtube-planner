# plan-target-positioning-v1.5.md

제품의 타겟과 포지셔닝을 수정한 내용을 기록합니다. **V1의 기술적 범위(`plan-v1-revised.md`)와 STEP 4-0 진행 방식은 이 변경으로 달라지지 않습니다** — 영상 분석 파이프라인 자체는 타겟이 누구든 동일하게 필요하기 때문입니다. 이 문서는 "누구에게, 어떤 메시지로" 제공할지를 다룹니다.

---

## 1. 타겟 변경

**기존 핵심 타겟**
- 유튜브를 처음 시작하려는 사람
- 어떤 주제/제목/썸네일을 정해야 할지 모르는 사람

**변경된 핵심 타겟**
- 이미 유튜브 채널을 운영 중
- 이미 자신의 채널 주제/장르가 있음
- 영상을 실제로 업로드하고 있지만 조회수나 성장이 기대만큼 안 나옴
- 혼자 또는 소규모로 기획·촬영·편집하고 있어 객관적인 피드백을 받기 어려움

---

## 2. 핵심 질문 변경

- 기존: "유튜브를 시작하려면 무엇을 해야 하는가?"
- 변경: "나는 이미 영상을 만들고 있는데, 왜 내 영상이 잘 안 되는지 업로드 전에 확인할 수 없는가?"

## 3. 핵심 포지셔닝

**편집이 끝난 영상을 바로 업로드하지 말고, 업로드 전에 AI에게 한 번 검수받는 서비스.**

## 4. V1 범위 — 변경 없음

```
편집본 MP4 업로드 → 영상 분석 → 문제 구간 탐지 → 타임스탬프 기반 피드백
```

`plan-v1-revised.md`에서 정리한 기술 아키텍처, DB 스키마, 피드백 항목 분류, STEP 로드맵은 그대로 유지합니다. 타겟이 "초보"에서 "이미 운영 중인 소형 채널"로 바뀌면서 달라지는 것은 UI 문구/온보딩 질문/마케팅 메시지 정도이고, 분석 기술 자체는 동일하게 필요합니다.

## 5. 기존 추천/제목/썸네일 기능 처리

`주제 입력 → 채널 주제 추천 → 제목 생성 → 썸네일 생성` 기능은 완전히 삭제하지 않지만, 핵심 유료 가치에서는 내립니다. 대신 다음과 같이 V2 후보로 재설계하는 것으로 기록합니다.

- (기존) "새로운 채널 주제를 정해주는 기능" → (V2 후보) **"현재 채널 방향을 분석하고 다음 영상 방향을 제안하는 기능"**
- 향후 V1 이후 확장 후보로 함께 기록: 현재 영상에 맞는 제목 분석/개선, 현재 영상에 맞는 썸네일 방향 분석, 수정 후 재분석, 수정 전/후 비교, 이전 영상들과의 패턴 비교

이 항목들은 아직 설계하지 않고 "V2 후보 목록"으로만 남겨둡니다.

## 6. STEP 4-0에 대한 영향

없음 — STT/OCR/scene-detection/low-motion/음량/블랙프레임 등 신호 분석은 타겟이 바뀌어도 동일하게 필요하므로 현재 진행 중인 feasibility PoC를 그대로 계속합니다. 다만 STEP 4-0 결과가 나오고 STEP 4-1(DB 마이그레이션)로 넘어가기 전에, 바뀐 타겟을 기준으로 V1 사용자 흐름과 온보딩 질문(기존 5문항)을 다시 한번 검토하는 단계를 추가합니다 — 이건 지금 하지 않고 STEP 4-0 이후로 남겨둡니다.

---

## 7. 마케팅 방향 메모 (기록용)

전달해주신 방향을 정리해 남겨둡니다. 실행은 아직 아니고 기록만 해둡니다.

- 핵심 메시지 후보: "업로드 버튼 누르기 전에, 한 번만 검사하세요" / "10시간 편집하고 그냥 업로드하지 마세요, 올리기 전에 한 번 검사하세요" / "조회수 안 나온 뒤 후회하지 말고, 업로드 전에 문제를 찾으세요"
- 좁힌 타겟: 구독자 0~1만, 꾸준히 올리지만 조회수가 기대에 못 미치고, 혼자 편집하는 사람
- 채널(021)을 제품 데모 겸 마케팅 채널로 사용하는 아이디어: 본인 영상을 직접 분석해 보여주는 콘텐츠, 수정 전/후 비교 콘텐츠
- 첫 영상 무료 분석으로 유입 → 결과 화면에서 유료 전환 유도
- 결과 카드를 이미지로 저장해 공유 가능하게 만들어 바이럴 유도
- 초기 10~30명은 광고 없이 커뮤니티에서 직접 섭외, 가입자 수보다 "실제로 도움이 됐다는 반응" 자체를 우선 지표로 삼음
- Before/After(수정 전 조회수 → 분석 → 수정 → 다음 영상 조회수) 콘텐츠를 장기적으로 가장 강력한 증거로 봄

**짧은 반응**: 방향 자체는 이 제품의 재포지셔닝과 잘 맞습니다. 특히 "업로드 전 검사"라는 습관을 만드는 메시지가 "AI 기능이 많다"보다 훨씬 구체적이고 반복 사용으로 이어지기 쉽다는 점에 동의합니다. 다만 이 모든 건 STEP 4-0에서 신호 정확도가 실제로 쓸 만하다고 확인된 다음에 의미가 있는 이야기라, 지금은 기록만 해두고 STEP 4-0 결과부터 보는 게 순서에 맞다고 생각합니다.
