# STEP 4-0 테스트 영상 촬영 스크립트 (게임 / 스토리·썰 / 정보형)

각 영상은 3~5분 분량이고, 아래 14개 테스트 포인트가 최소 1회씩 포함되도록 설계했습니다: 실제 편집 컷(여러 번), 컷 아닌 플래시/급변, 일반 자막, 컬러 자막, 테두리/그림자 자막, 큰 강조 자막, 중앙/상단 자막, 짧은 예능식 자막, 자막 없는 발화, 화면 변화 적은 구간, 실제 freeze, 음량 급증, 음량 과소, 블랙프레임.

촬영/편집하실 때 아래 타임라인을 그대로 따르실 필요는 없고, 각 구간이 "언제 어떤 테스트 포인트였는지"만 실제로 편집한 시각으로 `ground-truth-template.csv`에 기록해 주시면 됩니다. 이 문서의 초 표기는 어디까지나 촬영 가이드용 예시입니다.

| 구간 | 내용 | 테스트 포인트 |
|---|---|---|
| 0:00–0:10 | 인트로, 화면 중앙에 큰 강조 자막(예: "오늘 승률 1위 간다") | 큰 강조 자막, 중앙 자막 |

| 0:10–0:20 | 로딩 화면 설명, 하단에 평범한 스타일 자막 | 일반 하단 자막 |

| 1:50–2:05 | 속삭이듯 작은 목소리로 설명 | 음량 과소 |

## 라벨링 시 참고

- **게임 장르(game_01)는 2026-08-23 game_01 실측 PoC 결과에 따라 컷 분류를 3종으로 나눕니다.** "편집 컷"으로 표시된 지점은 화면 전체가 바뀌었는지, 메인 레이아웃은 유지된 채 PIP/인서트 영상만 바뀌었는지에 따라 `ground-truth-template.csv`의 `full_cut` 또는 `partial_edit` 행에 기록해 주세요. "플래시/급변(컷 아님)"은 게임 장르에서는 `game_visual_change` 행에 기록합니다(게임 내 카메라 이동/폭발/이펙트 등 편집 컷이 아닌 변화 전부 포함). 스토리·썰/정보형 장르는 기존대로 `cut` / `flash_non_cut` 2분류를 유지합니다(이 두 장르는 아직 PIP/인서트 레이아웃 문제가 발견되지 않았기 때문입니다 — 다만 실제 촬영 결과 유사한 애매함이 나오면 동일하게 재검토합니다).
- 실제로 촬영/편집하시면서 위 타임라인과 정확히 같은 초에 맞추실 필요는 없습니다. 실제로 편집한 시점을 그대로 기록해 주시면 됩니다.
- 20~30분짜리 처리시간/비용 테스트용 영상은 위 요소를 다 넣을 필요 없이, 평소 편집하시는 방식 그대로 만드신 영상이면 충분합니다.
- V1에서 이 항목을 사용자에게 보여줄 때는 "편집 컷 수" 같은 확정적 표현 대신 `visual change frequency`(화면 전환 빈도) 계열의 표현을 사용합니다 — game_01 PoC에서 컷/비컷 경계가 장르에 따라 애매할 수 있다는 것이 확인됐기 때문에, 검증이 충분해지기 전까지는 정확한 개수를 단정하지 않습니다.
